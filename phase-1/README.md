# Фаза 1. Выбор концепции проекта

![Статус](https://img.shields.io/badge/статус-готово-brightgreen)
![Концепция](https://img.shields.io/badge/концепция-Трекер_подписок-blueviolet)

Из четырёх концепций программного продукта команда выбирает одну, с которой работает в следующих фазах. Концепции сравниваются по пяти общим критериям двумя методами: нечётким коллективным TOPSIS и чётким коллективным методом анализа иерархий (МАИ). Экспертами выступили оба участника команды.

## Результат

Оба метода дали одинаковый порядок, выбрана концепция «Трекер подписок».

| Концепция | CC (TOPSIS) | Приоритет (МАИ) | Ранг |
| --- | --- | --- | --- |
| Трекер подписок | 0,4874 | 0,4876 | 1 |
| Доска домашек группы | 0,4333 | 0,2458 | 2 |
| Очередь на защиту лабораторных | 0,4041 | 0,1586 | 3 |
| Общие расходы с друзьями | 0,3597 | 0,1080 | 4 |
