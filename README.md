## Структура

| Папка | Фаза | Содержание |
| --- | --- | --- |
| `phase-1/` | Фаза 1. Выбор концепции проекта | концепции и критерии, экспертные оценки, нечёткий коллективный TOPSIS, чёткий коллективный МАИ, выводы |
| `phase-2/` | Фаза 2. Распределение работы | декомпозиция фазы 3, оценки трудоёмкости и предпочтений, задача о назначениях и её решение |
| `phase-3/` | Фаза 3. Оценка проекта | use case, COSMIC FP, UCP, коллективная экспертная оценка, выводы о масштабе |
| `phase-4/` | Фаза 4. Прогнозирование | трёхточечные оценки задач фазы 5, две модели Монте-Карло |
| `phase-5/` | Фаза 5. Планирование | задачи, ресурсы, предшествование, эвристики упорядочения, календарный план |
| `report/` | Итоговый отчёт | все фазы, матрица RACI и обоснование распределения задач |

## Фазы

### Фаза 1. Выбор концепции проекта

Готово. Из четырёх концепций по пяти критериям выбран «Трекер подписок»: нечёткий коллективный TOPSIS и чёткий коллективный МАИ дали одинаковый порядок. Подробности, расчёты и вывод в [`phase-1/`](phase-1/).
